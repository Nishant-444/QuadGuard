Guarded Bipartite Matching Formulation

QuadGuard solves an online $V \times (V + I)$ bipartite matching matrix at every minute step using SciPy Hungarian assignment:

Cost(v, i) = Distance(v, i) - λ · Weight(i) + Penalty(v)
  • Dummy Columns ($V \times V$): Priced at 200.0 to allow vehicles to stay idle when dispatching causes coverage depletion.
  • Guard Penalty (1000.0): Added for non-P3 incidents if vehicle $v$ is the last remaining idle unit in its quadrant.
  • P3 Override: Priority-3 emergencies ($w=7$) bypass penalties for immediate life-safety response.
⚡

Multi-Vehicle Simultaneous Repair Pass

Single-unit checks (quad_counts == 1) don't trigger when a quadrant has 2+ idle units. If the assignment solver attempts to dispatch all idle units in a single minute step:

  • Detection: QuadGuard identifies simultaneous multi-unit batch departures per quadrant.
  • Automated Repair: The repair_pass drops the lowest-priority non-P3 assignment, guaranteeing at least 1 vehicle stays in idle coverage.
  • Zero Future Knowledge: Operates minute-by-minute with 100% causal compliance.
